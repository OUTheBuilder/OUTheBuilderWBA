# OU The Builder WBA

OU The Builder Web-Based Application.

This project is the web-based version of OU The Builder.

## Goals

- Web-based builder interface
- AI chat as the central control interface
- Project and file management
- Remote APK build/compile system
- Build console and logs
- Google Drive storage integration
- Temporary-file cleanup
- Web application preview and flow visualization

## Architecture

Frontend: Web Application

Backend: Remote services / build automation

Build System: GitHub Actions

Storage: Google Drive integration where appropriate
